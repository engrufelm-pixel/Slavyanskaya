# Славянская мастерская — сайт автоателье

Премиальный одностраничный лендинг для мастера по пошиву и реставрации
автомобильного интерьера. Стиль — Premium Automotive Luxury (тёмная палитра,
золотой акцент, serif-заголовки).

## Стек

- **Next.js 15** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS** (тема и палитра — в `tailwind.config.ts`)
- **Framer Motion** — аккуратные появления, слайдер, аккордеон, лайтбокс
- **Phosphor Icons** — иконки (без эмодзи)
- Шрифты через `next/font` — **Playfair Display** (заголовки) + **Manrope** (текст)

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшн-сборка
npm run start    # запуск собранной версии
```

## Как заменить контент

Почти весь контент собран в одном файле — **`lib/site.ts`**. Разметка
подстраивается автоматически.

| Что меняем | Где в `lib/site.ts` |
|---|---|
| Название ателье | `brand.name`, `brand.tagline` |
| Телефон, ссылка на Max, e-mail | `contacts` |
| Адрес и координаты для карты/Schema | `contacts.address`, `contacts.geo` |
| Часы работы | `contacts.hours` |
| Заголовок/подзаголовок Hero | `hero` |
| Преимущества (4 карточки) | `advantages` |
| Галерея работ (≥12) | `gallery` |
| Услуги и подпункты | `services` |
| Этапы работы | `process` |
| Отзывы (≥6) | `reviews` |
| Текст «О мастерской» и цифры | `about` |
| FAQ | `faq` |
| SEO title/description/домен | `seo` |

> **Важно перед публикацией:** замените телефон и ссылку на профиль Max (`contacts.max`,
> сейчас заглушка `https://max.ru/`) в
> `contacts` на реальные — на них завязаны все кнопки и форма заявки.

## Фотографии

Сейчас в галерее, Hero и блоке «О мастерской» стоят временные цветные стоковые
фото авто-интерьеров с `images.pexels.com` (бесплатная лицензия Pexels). Их нужно
заменить на реальные фото работ мастерской.

Чтобы поставить реальные фото:

1. Положите снимки в папку `public/` (например, `public/works/bmw-x5.jpg`).
2. В `lib/site.ts` замените `src` (галерея), `hero.bg` и `photos.about` на пути
   вида `/works/bmw-x5.jpg`.
3. После того как все картинки станут локальными, можно удалить блок
   `images.remotePatterns` в `next.config.mjs`.

Рекомендуемые размеры: горизонтальные ~1200×900, вертикальные ~900×1200,
формат JPG/WebP, вес до ~300 КБ для хорошего Lighthouse.

## Карта

Карта Яндекса грузится **по клику** (паттерн «фасад») — это бережёт скорость
загрузки и Lighthouse. Адрес подставляется из `contacts.addressFull`.
Кнопка «Построить маршрут» открывает Яндекс.Карты с маршрутом до адреса.

## Форма заявки

Форма «Получить расчёт стоимости» проверяет имя и телефон, открывает мессенджер
**Max** и показывает успех (мастер перезванивает по оставленному номеру).

⚠️ Без бэкенда заявка **не сохраняется на сервере** — Max не поддерживает
предзаполненный текст по ссылке. Чтобы реально получать заявки (Max-бот /
Telegram-бот / e-mail / CRM), раскомментируйте `fetch('/api/lead', …)` в
`components/LeadForm.tsx` и добавьте обработчик `app/api/lead/route.ts`.

## SEO

- `title`, `description`, Open Graph, Twitter — в `app/layout.tsx` (берутся из `seo`).
- Schema.org **LocalBusiness/AutoRepair** с адресом, телефоном, часами и услугами —
  генерируется автоматически в `app/layout.tsx`.
- Замените `seo.url` на реальный домен и положите OG-картинку `public/og.jpg`
  (1200×630), затем пропишите её вместо плейсхолдера в `app/layout.tsx`.

## Структура

```
app/
  layout.tsx      # шрифты, SEO-метаданные, Schema.org, зерно
  page.tsx        # сборка секций
  globals.css     # базовые стили, утилиты, плавный скролл
components/        # секции и UI (Header, Hero, Gallery, Reviews, …)
lib/site.ts        # ВЕСЬ контент сайта
```
